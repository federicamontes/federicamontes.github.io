PRELIMINARI:

0. Si implementi la funzione: void reverse(Node** head); presente nel pacchetto singly-linked-list.c mostrato a lezione.
La funzione deve invertire l'ordine dei nodi di una lista semplicemente collegata in-place, ovvero senza allocare nuovi nodi in memoria 
e senza duplicare i dati esistenti. La testa della lista (head) deve essere aggiornata correttamente per puntare al 
nuovo primo elemento (che in origine era l'ultimo).

0.1. Si implementi la funzione void insertOrdered(Node **head, Node *newNode); presente nel pacchetto singly-linked-list.c mostrato a lezione.
La funzione deve inserire un nuovo nodo (newNode) all'interno di una lista semplicemente collegata 
che mantiene già un ordinamento crescente basato sul campo data.
La ricerca del punto di inserimento deve essere effettuata utilizzando un puntatore a puntatore (Node **prec), 
e l'inserimento finale deve riutilizzare la funzione generica insert(Node **prec, Node *newNode) vista a lezione.

0.2. Implementare l'Abstract Data Type (ADT) Stack (Pila) sfruttando la struttura delle liste semplicemente collegate. 
Lo Stack deve seguire rigorosamente la politica LIFO (Last In, First Out).
La definizione della struttura è:
typedef struct StackNode {
    int data;
    struct StackNode* next;
} StackNode;

Specifiche delle operazioni richieste:
- void push(StackNode** top, int data); Inserisce un nuovo elemento in cima allo Stack
- int pop(StackNode** top); Rimuove e restituisce l'elemento attualmente in cima allo Stack
- int peek(StackNode* top); oppure int top(StackNode* top); Restituisce il valore dell'elemento in cima allo Stack senza rimuoverlo
- bool isEmpty(StackNode* top); Restiuisce true se lo stack è vuoto, false altrimenti
- StackNode* createStackNode(int data); Crea la struttura StackNode e ritorna il puntatore
- void freeStack(StackNode** top); Libera la memoria dello stack


0.3 Implementare l'Abstract Data Type (ADT) Queue (Coda) utilizzando i nodi di una lista semplicemente collegata. 
La Coda deve seguire rigorosamente la politica FIFO (First In, First Out).
La definizione delle strutture è:
// Nodo della coda
typedef struct QNode {
    int data;
    struct QNode* next;
} QNode;

// Struttura di controllo della Coda con i campi front e tail
typedef struct Queue {
    QNode* front;
    QNode* tail;
} Queue;

Specifiche delle operazioni richieste:
- void enqueue(Queue* q, int value); Inserisce un nuovo elemento in fondo (in coda) alla struttura.
- int dequeue(Queue* q); Rimuove e restituisce il primo elemento della Coda (quello inserito per primo).
- int first(Queue* q); Restituisce il valore del primo elemento della Coda senza rimuoverlo.
- bool isEmpty(Queue* q); Restituisce true se la coda è vuota, false altrimenti
- Queue* createQueue(); Crea la struttura Queue e i suoi nodi iniziali Qnode* e ritorna il puntatore a Queue
- void freeQueue(Queue* q); Libera la memoria della coda

6*. Scrivi una funzione in linguaggio C che prenda in input le teste (head1 e head2) di due liste semplicemente collegate e già ordinate in ordine crescente. 
La funzione deve costruire e restituire una nuova lista collegata che contenga tutti gli elementi comuni (l'intersezione).
Gestione dei duplicati: Se un elemento è presente più volte in entrambe le liste, deve comparire nella lista intersezione tante volte 
quanto è il minor numero di ripetizioni comuni in entrambe le liste.
Invariabilità: Le due liste originali non devono essere modificate in alcun modo.

Input (Lista 1): 1 -> 2 -> 2 -> 3 -> 4 -> 6 -> NULL
Input (Lista 2): 2 -> 2 -> 4 -> 6 -> 6 -> 8 -> NULL

Output atteso (Nuova lista intersezione): 2 -> 2 -> 4 -> 6 -> NULL
(Spiegazione: il 2 compare due volte in entrambe, il 4 una volta, il 6 compare una sola volta nell'intersezione perché nella Lista 1 ce n'è solo uno, 
mentre il 3, l'1 e l'8 vengono esclusi).

Qual è la complessità temporale e spaziale nel caso peggiore (worst-case) di questo algoritmo, sfruttando il fatto che le liste di partenza sono già ordinate?

9*. Data una lista collegata, scrivi una funzione C che ordini la lista in senso crescente. L'ordinamento si può fare in tempo O(N^2) e O(NlogN). Discuti e implementa la soluzione con entrambi 
gli algoritmi. Implementa un algoritmo di ordinamento quadratico (come il Selection Sort o l'Insertion Sort modificato per le liste), operando direttamente sui puntatori.
Implementa il Merge Sort, sfruttando la divisione della lista a metà e una funzione di supporto merge per fondere le due parti.

Hint: pensa a come funziona l'ordinamento su un array, nel caso dei due algoritmi O(N^2) e O(NlogN). 
- Pensa a come sposti o riagganci i puntatori next senza dover per forza accedere agli elementi tramite indice numerico ([]). 
Puoi aiutarti isolando un sottoinsieme di nodi già ordinati e inserendo i successivi uno alla volta nella posizione corretta.
- Ricordati il paradigma Divide et Impera. Per applicarlo a una lista collegata:
Divide: Come puoi trovare il punto di mezzo di una lista senza calcolarne prima la lunghezza esatta?
Impera: Sfrutta la ricorsione per spezzare la lista in metà sempre più piccole fino a singoli nodi.
Combina (Merge): Scrivi una funzione di supporto che prenda due liste già ordinate e le fonda in un'unica lista ordinata, 
manipolando unicamente i puntatori next (senza sprecare memoria extra per array di supporto).
